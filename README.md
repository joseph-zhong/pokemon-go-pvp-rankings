# pokemon go pvp rankings

## Goal: 

stadiumgg.com is basically what I previously used to look up pvp pokemon go
rankings, but it has a bunch of ads and is quite slow. I don't really see why, 
this should basically be a 'calculator' that should instantaneously return and
never go out of date. 

Should be a simple website with a simple but very smooth and easy to use UI,
whatever the best practices are for typeahead typing for a fixed pokemon list
and 0-15 for each of the stats. 

Hosted on CloudFlare pages, zero cost, zero bullshit. 

## How it works

See [`plans/design-doc.md`](plans/design-doc.md) for the full write-up. Short
version: this is a pure calculation, not a database — for any Pokemon, walk
each of the 4096 possible IV combos to the highest level under a league's CP
cap, sort by stat product, and your rank is where you land. It runs
client-side in under a millisecond; there's nothing to look up.

## Development

```sh
npm install
npm run dev      # local dev server
npm test         # vitest — calc engine is unit tested against known values
npm run build    # typecheck + production build into dist/
```

Deploys via Cloudflare Pages: build command `npm run build`, output directory
`dist`. `main` is protected — all changes land via PR (see `ci.yml`).

## Data

`public/data/pokemon.min.json` (species id, name, dex, base stats) is
generated by `scripts/fetch-gamemaster.mjs` from
[pvpoke/pvpoke](https://github.com/pvpoke/pvpoke)'s `gamemaster.json` (MIT
licensed) and refreshed daily via `.github/workflows/update-data.yml`, which
opens a PR rather than pushing directly. Run it manually with
`npm run fetch-data`.
